Kurzbeschreibung
----------------
Z9D-SRS v5.3-PRO ist eine Sicherheits- und Lizenzplattform fuer Robotereinheiten,
Fernsteuerungen, autonome Systeme, KI-Robotik, OEM-Integrationen sowie gekoppelte
Control-/Robot-Installationen. Die Software ist fuer Robotikgeraete, Drohnen,
Industrieanlagen, Service-Roboter, AMR/AGV, Humanoide Systeme sowie die zugehoerigen
Steuerungsgeraete wie Laptop, PC oder Server ausgelegt.

Hauptziele
----------
- Schutz gegen Fremdeingriff, Remote-Manipulation und unerlaubte Funkverbindungen
- Ueberwachung lokaler Prozesse, Netzwerkaktivitaeten und sicherheitsrelevanter Ereignisse
- Lizenzierung pro Robotereinheit, pro Pack und fuer OEM-Ausrollungen
- Twin-Lizenzmodell fuer 1 Robot-Node + 1 Control-Node
- Mehrfachsteuerung fuer 1 Control-Node -> mehrere Robot-Units pro Pack
- 3% Skonto bei Sofortueberweisung
- Alle Preise exkl. Umsatzsteuer
- Offline-faehige, FTP-faehige, servergestuetzte Freigabe ohne oeffentlichen Sourcecode

Auslieferungsmodell
-------------------
- Verteilung als EXE / ZIP
- Keine oeffentliche Bereitstellung des Programmcodes
- Optionaler Download ueber GitHub ZIP / Release / Blob-Link
- Zahlungsarten: Rechnung, Bankueberweisung, SEPA, Sofortueberweisung, PayPal-Manuell, OEM-Sonderfreigabe
- Bei Sofortueberweisung werden 3% Skonto auf den Listenpreis gewaehrt
- Im Adminbereich koennen mehrere Empfangskonten pro Land, Waehrung und Zahlungsart gepflegt werden
- Dadurch sind z. B. ein EUR-Devisenkonto, ein lokales Tekuci-Racun / Landesbankkonto sowie ein optionales PayPal-Konto parallel moeglich
- Standard-PayPal-Link kann z. B. als PayPal.Me-Adresse hinterlegt werden
- PayPal kann fuer kleinere bis mittlere manuelle Zahlungen begrenzt bleiben; sehr grosse Orders sollen ueber Bank/OEM laufen
- Weitere Laenderkonten (z. B. Russland, China, USA oder spaeter Doboj/BA) koennen bei Bedarf spaeter nachgetragen werden
- Das Lizenzformular und die Statusseite zeigen automatisch das passendste Konto fuer Land, Waehrung und Zahlungsart an

Lizenzmodelle
-------------
1. SingleRobot
   - Eine einzelne Robotereinheit

2. TwinRobotControl
   - Ein Robot-Node und ein gekoppelter Control-Node
   - Z. B. Robotersystem + Steuerungslaptop

3. ControlMultiRobotPack
   - Ein Control-Node steuert mehrere Robot-Units
   - Geeignet fuer Flotten, Leitstellen, OEM-Zellen, AMR-Gruppen, Drohnenschwaerme

4. RobotPack / OEM-Packs
   - Mehrere Lizenzen in 10 / 100 / 1000 / 10000 / 100000 / 1000000 Groessen
   - Sehr grosse Packs und OEM-Massenrollouts bleiben administrativ als Sonderpruefung sichtbar

Sicherheitsfunktionen
---------------------
1. Prozesssensorik
   - Ueberwacht laufende Prozesse
   - Bewertet verdachtige Namen, Last, Handles und untypisches Verhalten

2. Netzwerksensorik
   - Analysiert aktive Netzwerkverbindungen
   - Erkennt riskante Zielverbindungen und auffaellige Kommunikationsmuster

3. Ereignissensorik
   - Bewertet sicherheitsrelevante Windows-Ereignisse
   - Verwendet kalibrierte Zeitfenster zur Vermeidung ueberaggressiver Fehlalarme

4. Defender-/Systemschutzsensorik
   - Einbindung von Windows-Sicherheitsinformationen

5. Funk- und Wireless-Schutz
   - WiFi / WLAN
   - Bluetooth
   - Radio / Funk
   - Profilbasierte Freigaben je Robotiktyp
   - Monitorprofil fuer Laptop-/Testbetrieb
   - Funk-Sperre fuer nicht freigegebene Adapter / Transportwege

6. KI-/Automatikschutz
   - Lokale oder externe KI-Analyse moeglich
   - Modi: NONE, AUTO, PYTHON, OPENAI, OPENAICOMPAT, AZUREOPENAI, NVIDIA,
     ANTHROPIC, TEXTGENWEBUI, KOBOLDCPP, LMSTUDIO, OLLAMA, Z9DENGINE

Pairing- und Cluster-Funktionen
-------------------------------
1. Twin-Lizenzmodell
   - Verknuepft Robot-Node und Control-Node
   - Pairing-Status in der UI sichtbar
   - Gemeinsame Pair-ID fuer zusammengehoerige Systeme

2. Mehrfachsteuerung
   - 1 Control-Node kann mehrere Robot-Units in einer Lizenzanfrage fuehren
   - Robot-Units werden als CSV, Leerzeichen- oder Zeilenliste erfasst
   - Bei Freigabe erzeugt der Server:
     - eine Control-Lizenz fuer den Leit-/Steuerknoten
     - einzelne Robot-Lizenzen fuer alle aufgefuehrten Robot-Units

3. Pairing-Statusanzeige
   - Single-Node
   - Twin-Lizenz
   - Control-Cluster
