# Z9D-SRS v5.3 PRO

Z9D-SRS v5.3 PRO is the robotic-system edition included in this repository as a published executable package.

## Package

- **Archive:** `Z9D-CSS-v5.3-PRO-SRS-EXE.zip`
- **Main repository:** https://github.com/Z9D-QAI/Z9D-QAI-SRS-SECURE-ROBOTIC-SYSTEM
- **Official website:** https://z9d-qai.com/
- **Support:** Z9D-CSS@outlook.com

## Overview

Z9D-SRS v5.3 PRO provides monitoring and licensing functions for robots, control stations, autonomous systems and approved fleet deployments. Supported features depend on the delivered edition and activation.

Typical areas include:

- process and network monitoring;
- remote-IP and wireless-transport analysis;
- local incident and quarantine handling;
- device-role and pair configuration;
- single-device, twin and control-cluster licensing.

## Start

1. Extract the official ZIP package.
2. Start the supplied executable on Windows.
3. Record the displayed device ID.
4. Select the appropriate product and manufacturer profile.
5. Set `ROBOT_NODE` or `CONTROL_NODE` as applicable.
6. Submit the license request and wait for authorization.

Use only devices and systems you own or are authorized to operate.
